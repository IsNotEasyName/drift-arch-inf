DriftArchInf

Экспериментальный дистрибутив на базе Arch Linux с бесконечным холстом.

Скачать ISO GitHub

Что внутри:

  • ♾️ driftwm: бесконечный плавающий композитор на Wayland.
  • 📦 Arch Linux: свежие пакеты и AUR (yay-bin уже установлен).
  • 📱 Waydroid: поддержка Android-приложений.
  • ⚡ NVIDIA: автоопределение драйверов через chwd.
